## Symbol key

- Rectangles marked D/Q with a triangle are clocked registers; the triangle is the clock pin.
- Trapezoids are combinational multiplexers. Data and control input positions are explicit.
- Circles marked × and + are multiplication and addition, with no implicit pipeline stage.
- A slash across a wire marks its bus width. D denotes DATA_W; W denotes ACC_W.
- Teal wires carry A/data/arithmetical values; blue carries B operand hops; purple carries accumulated results. Dashed amber wires show selected control nets.
- Repeated net labels identify the same signal when a full routed connection would obscure the datapath.

The core view illustrates a physical 4×4 mesh. Each PE passes a D-bit operand and its valid bit to its neighbor; each keeps a W-bit accumulator. The result snapshot captures all N² accumulators in parallel. The output address mux and quantizer select one result at a time.

The PE forwarding registers group data and valid into D+1-bit bundles in the drawing. They correspond to the separate RTL data and valid registers with common enable/clear/reset. Forwarding uses global enable, whereas the accumulator uses execute_mac. Operand isolation muxes are combinational; there is no product register between the multiplier and adder.

The banking figure shows selected initialized bits accompanying each bank's selected payload. Read qualification chooses zero for invalid/uninitialized lanes. The ownership check drawn underneath is in edgegemm_core, outside operand_buffer. Memory grids represent register/distributed storage rather than synchronous SRAM macros.

The affine view uses default ACC_W=32 and OUT_W=8: 33-bit bias addition, 17-bit positive scale representation, 50-bit product and 51-bit guarded shift/zero-point values. Both shift modes and their selection appear in the drawing. Quantization has no additional register stage.

## Regenerate

```bash
# Standard-library Python only: editable SVG drawings
make figures

# PNG/PDF exports require Inkscape or the optional cairosvg package
python3 tools/draw_figures.py --png --pdf

# Refresh the waveform from a newly generated VCD
make wave
python3 tools/draw_figures.py --png --pdf --waveform build/core.vcd
```

The hardware artwork is generated by tools/hardware_figures.py; the schedule/trace renderer is tools/draw_figures.py. Existing RTL and verification results are unchanged by this figure revision.
