# Testbench guide

Each of the 16 RTL modules has `tb/tb_<module>.sv`. The shared `tb_util.svh` CHECK macro treats X/Z in a checked Boolean as failure and calls `$fatal`; it also counts checks. A global time watchdog prevents hangs. The retained legacy top bench uses its original self-checking/error style.

Run a particular bench:

```bash
python3 tools/run_tests.py --module signed_mac
python3 tools/run_tests.py --module edgegemm_core --vcd
```

Override a bench parameter directly:

```bash
mkdir -p build
iverilog -g2012 -Wall -Itb -f rtl/files.f \
  -s tb_edgegemm_core -Ptb_edgegemm_core.N=3 \
  -Ptb_edgegemm_core.K_MAX=7 -Ptb_edgegemm_core.DATA_W=4 \
  -o build/core_int4.vvp tb/tb_edgegemm_core.sv
vvp build/core_int4.vvp
```

| Bench | Main corner cases |
|---|---|
| `tb_signed_mac` | 1200 seeded cycles; extrema, zero, clear, pause, invalid and overflow |
| `tb_pe` | Original interface forwarding, hold, clear and signed accumulation |
| `tb_systolic_pe` | Independent A/B valids, masked data and paused token state |
| `tb_systolic_mesh` | All small M/N shapes, K=1..5, two pauses per active step |
| `tb_operand_buffer` | Non-power-of-two 3×5 storage, banks, masks, invalid selectors, reset |
| `tb_skew_injector` | Exhaustive M/N/K windows over 3×3/K_MAX=5 |
| `tb_tile_controller` | Legal small dimensions, invalid/zero depth, exact cycles and pauses |
| `tb_perf_counters` | MAC popcounts, zero counts, idle/pause qualification and clear |
| `tb_result_buffer` | Snapshot independence, signed readback, invalid index and reset |
| `tb_result_streamer` | All 1..3 row/col shapes, input shape changes, three-cycle stalls per beat |
| `tb_channel_config` | Banked tuples, reset identities, invalid writes/read defaults |
| `tb_requantize` | 4096 shifts/sign/extreme/ReLU cases |
| `tb_affine_requantize` | 9230 checks including explicit positive/negative half-way rounding |
| `tb_systolic_array` | Twelve repeat legacy GEMMs per configuration |
| `tb_edgegemm_top` | Original C-generated 4×4 known-answer test and legacy quantization |
| `tb_edgegemm_core` | Full host protocol, random backpressure/pause, alternate-bank overlap, active-bank blocking, invalid requests, restart/reset, exact counters, independent Python vectors |

Only the marked job in `tb_edgegemm_core` is used for the waveform preview. `+vcd` enables its VCD generation. File vectors are checked in and regenerated by `make vectors`.
